# Al Bhitai Filling Station

Management desk for fuel purchases, nozzle sales, tanks, customers, suppliers, and accounts.

The app runs in the browser. Sample records load on the first visit and stay in that browser. Use **Reset sample data** in the sidebar to restore them.

Invoices and reports can be printed or downloaded as PDF.

The public site is published from the `gh-pages` branch. A GitHub Actions workflow is saved at `deploy/github-pages.yml` for a later move into `.github/workflows/` once the GitHub token includes the workflow scope.
